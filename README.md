# 大正九年 旧市町村チェックイン

公開サイト: https://zubing-inc.github.io/taisho9-map/

1920年（大正9年）の旧市町村を地図で巡り、ブラウザ内へチェックインを記録するWeb版です。訪問履歴は同じブラウザ内へ自動保存され、JSON形式で書き出し・読み込みできます。対応するAndroid端末では、共有先またはファイル選択先としてGoogle Driveを利用できます。

> ブラウザ版のため、サイトを閉じている間のバックグラウンド常時チェックインには対応していません。

この公開リポジトリには配信用に圧縮・難読化した成果物だけを収録しています。開発元コードは公開していません。ただし、Webブラウザへ配信するコードや区域データを完全に秘匿することはできません。

旧市町村区域はCODH「Geoshapeリポジトリ（歴史的行政区域データセットβ版）」を加工して利用しています。区域データはCC BY-SA 4.0です。背景地図は© OpenStreetMap contributorsです。詳しくは`NOTICE.txt`を参照してください。
